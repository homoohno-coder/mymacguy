Returns & Exchanges

Policy

We stand behind every handmade piece. If something is not right, contact Elena before sending anything back.

Return Details

Our policy.

Please email Elena first so she can issue a Return Merchandise Authorization number and help resolve the issue quickly.

Return Window

Returns are accepted within 14 days of delivery. Items must be unworn and in original condition.

Restocking Fee

A 15% restocking fee applies to returned items unless the return is due to our error.

Return Shipping

Customer is responsible for return shipping costs unless the item was damaged or incorrect.

Get an RMA First

Email Elena before sending a return so she can provide a Return Merchandise Authorization number.

Our Error

If the wrong item was sent or it arrived damaged, Fun Travel will cover return shipping and issue a full refund.

Condition of Returns

Items returned in worn, damaged, or altered condition cannot be accepted for a refund.
