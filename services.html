01 / Mac

Mac Repair & Tune-Up

From $140/hr · 1-hour minimum · estimates verbal

When a Mac slows down, freezes, refuses to boot, or starts making fan noise like a hair dryer, the answer is almost never "buy a new one." The answer is a real diagnosis.

I work data-first: anything important comes off the machine before I open it up. Then I walk through the actual cause — storage, RAM pressure, a failing SSD, a runaway daemon, a botched update — and tell you what it'll cost to fix in money and time. You decide.

  • Full hardware + software diagnostics
  • Storage upgrades (SSD swap where possible)
  • Time Machine + cloud backup setup
  • Migration between machines
  • macOS reinstall and clean rebuild
  • Performance audit and cleanup
  • Battery health assessment
  • Written summary after every visit

03 / Network

Wi-Fi & Networking

From $160/hr · projects quoted flat

Bad Wi-Fi is rarely a "buy a better router" problem. It's a layout problem.

I bring real survey tools, walk the space, find the dead zones, and design coverage around how you actually live — not the picture on the box. For small offices: secure SSIDs, guest networks isolated from your business traffic, VPN setup, printer reliability, and a network map you can hand to anyone who comes after me.

  • Wi-Fi site survey and heat-mapping
  • Mesh design (eero, Orbi, UniFi)
  • Wired backhaul recommendations
  • Guest VLAN and IoT isolation
  • Router and firmware hardening
  • ISP negotiation and equipment returns
  • Print server reliability
  • VPN setup (Tailscale, WireGuard)
04 / Cloud

iCloud & Backup

From $140/hr · strategy session ≈ 90 min

iCloud is not a backup. Time Machine alone is not a backup. A real strategy has three copies, two media, one off-site.

I audit what you have today, sketch what you actually need, then implement: local Time Machine to a fast drive, encrypted cloud backup, and a recovery plan that you can execute alone if something happens to me. Photos libraries get particular attention — they're where most people accidentally lose the most.

  • 3-2-1 backup architecture
  • Time Machine setup and verification
  • Backblaze / iDrive / Arq configuration
  • Photos library de-duplication
  • iCloud Drive strategy and quota planning
  • Data recovery from failed drives
  • Document recovery walk-throughs
  • Family disaster-recovery plan
05 / Security

Security & Privacy

From $160/hr · audits flat-quoted

Most people aren't being hacked. They're being inconvenienced by their own forgotten passwords, lost trusted devices, and well-meaning ad-blockers that broke their email.

I sort out the actual security posture, fix what's wrong, and teach you the three or four habits that matter. Apple ID lockouts, 2FA migrations between phones, password manager setup, and a privacy audit room-by-room. For the rare client who needs more — encrypted file containers, secure deletion, threat-model conversation — I do that too.

  • Apple ID lockout recovery
  • Two-factor migration / backup codes
  • Password manager (1Password, Bitwarden)
  • FileVault encryption setup
  • Privacy settings audit
  • Family safety configuration
  • Suspected-compromise triage
  • Estate / executor access planning
